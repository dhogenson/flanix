# Guide for branch and commit naming
This doesn't have to be crazy, I just want a clean git history

## Branch
Pattern: [type]/[short-description]

**Types:**
- `feature/` - use when adding a new feature or new functionality
- `fix/` - bug fixes
- `hotfix/` - urgent production fixes (don't know if we need that right now)
- `chore/` - maintenance, deps, and tooling
- `refactor/` - code restructuring
- `docs/` - documentation
- `test/` - adding or fixing tests
- `perf/` - performance improvements 

## Commit messages

Pattern: [type]: [short-description]

And the types are the same as for branches
